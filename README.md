# Retail Analytics Dashboard

An interactive retail analytics dashboard built with React, exploring two different approaches to data processing and frontend data handling.

## Overview

This project explores two ways of powering the same analytics dashboard:

- **Flask API Approach:** A Python Flask backend processes CSV data and sends calculated results to the React frontend through JSON APIs.
- **Client-Side Approach:** CSV data is bundled with the frontend, allowing React to process and calculate analytics directly in the browser.

Both approaches provide an opportunity to compare architectural decisions and understand their trade-offs.

## Key Concepts

- Backend API integration using Flask
- Client-side data processing with JavaScript
- CSV data handling
- React-based dashboard development
- Data visualization
- Performance, scalability, and deployment trade-offs

## Tech Stack

- React
- JavaScript
- Python
- Flask
- CSV

## Project Purpose

The goal is to understand when data processing should happen on the backend and when it makes sense to handle it directly in the frontend.

The project demonstrates how architectural choices affect performance, scalability, data exposure, and deployment simplicity.
